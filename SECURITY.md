# Política de segurança

## Versões suportadas

A versão estável publicada no WordPress.org recebe correções de segurança. Neste momento, a linha suportada é:

| Versão | Suporte |
| --- | --- |
| 1.0.7 | Sim |
| 1.0.6 e anteriores | Atualizar para 1.0.7 |

## Como relatar

Não publique vulnerabilidades, tokens, senhas, certificados, dados de compradores ou detalhes exploráveis em uma issue pública.

Envie um relato privado para `contato@vilahub.com.br` com:

- versão do plugin, WordPress, WooCommerce e PHP;
- tipo de falha e impacto possível;
- passos mínimos para reprodução;
- evidência sanitizada;
- forma segura de contato.

Não inclua credenciais reais. Se o teste exigir uma conta, descreva o cenário para combinarmos um ambiente controlado.

## Escopo

São relevantes falhas no código ou distribuição do plugin, incluindo autorização, isolamento de instalação, validação de entrada, exposição de segredos, dependências e integração com o serviço VilaHub.

Problemas internos de um marketplace, painel de terceiros ou conta do cliente devem ser tratados com o respectivo provedor e com o suporte oficial do plugin.

## Divulgação

O relato será confirmado e investigado antes de qualquer publicação detalhada. A correção e a orientação aos usuários serão publicadas quando o risco puder ser comunicado com segurança.
