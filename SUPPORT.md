# Suporte

## Instalação e uso

Use o fórum oficial:

https://wordpress.org/support/plugin/vilahub-for-woocommerce/

Inclua:

- versão do plugin, WordPress, WooCommerce e PHP;
- etapa em que o problema ocorre;
- mensagem exibida, sem dados sensíveis;
- se a conta do marketplace já foi autorizada.

## Antes de publicar um relato

- confirme que WooCommerce 9.0 ou superior está ativo;
- verifique se o cron do WordPress e o Action Scheduler estão executando;
- autorize novamente uma conexão antiga quando o canal solicitar novos escopos;
- teste com poucos produtos antes de ampliar a sincronização;
- remova nomes, e-mails, endereços, pedidos, tokens, certificados e credenciais.

## Segurança

Vulnerabilidades devem seguir a política em `SECURITY.md` e não devem ser publicadas como issues abertas.

## Serviço VilaHub

A instalação do plugin é gratuita. As operações externas dependem de uma conta VilaHub, do plano vigente e das permissões de cada marketplace.
